MY SELECT — 総合おすすめ・商品選びガイド

【ファイル構成】
- index.html：トップページ（カテゴリー絞り込み機能付き）
- guide-*.html：オリジナル記事10本
- about.html：運営者情報
- privacy.html：プライバシーポリシー
- disclaimer.html：免責事項
- style.css：共通デザイン

【GitHubへのアップロード】
ZIPを解凍し、中にあるファイル一式をGitHubリポジトリの最上位（root）へアップロードしてください。
index.htmlがリポジトリ直下に置かれる必要があります。フォルダごと入れ子にしないでください。

【公開前に必ず変更する項目】
1. about.html の運営者名・サイトURL・お問い合わせ先を実際の情報に変更。
2. privacy.html の広告・アクセス解析の記載を、実際に導入するサービスに合わせる。
3. Amazonアソシエイト登録後、Amazon公式規約に従った開示文言を目立つ場所に追加。
4. 審査承認後、Amazonが発行した専用リンクを各商品紹介箇所に設定。承認前はアソシエイトリンクを掲載しない。
5. 記事を自分で読み直し、実際に確認した事実・一次情報・独自の比較観点を追加して継続更新する。
6. お問い合わせ先を実際に受信できる状態にする。

【重要】
このサイトは10本の選び方ガイドを含む初期版です。商品を実際に使ったと偽るレビューは掲載していません。Amazonアソシエイトの審査通過を保証するものではありません。審査要件・規約は変更されることがあるため、申請時にAmazon公式ヘルプを確認してください。
